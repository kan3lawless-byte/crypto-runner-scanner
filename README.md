# Crypto Runner Scanner

Continuously scans cryptocurrency markets for active momentum runners.

Markets:
- Kraken spot
- Coinbase spot
- Bybit USDT perpetuals
- OKX perpetuals

Signal states:
- IGNITION
- RUNNING
- STRONG RUNNING
- FADING

The scanner is direction-neutral:
- LONG runners
- SHORT runners

Signals are sent to Telegram.

The scanner does NOT place trades.
KCEX and BTCC should be checked manually before entry.
